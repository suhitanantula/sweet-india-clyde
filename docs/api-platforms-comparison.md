# API Platform Comparison — WhatsApp Business API for Sweet India Clyde

*Evaluation for Phase 1 platform selection.*

---

## The Three Contenders

### WATI
- **URL:** wati.io
- **Pricing:** US$49–99/month (depends on plan)
- **Free trial:** Yes (7 days)
- **Australian support:** Yes (Sydney-based team)
- **Strengths:**
  - Best template management tools
  - Strong broadcast analytics
  - Team inbox for customer replies
  - Good API for Phase 2 integration
  - Webhook support
- **Weaknesses:**
  - Higher price point
  - Learning curve for non-technical users
- **Template approval:** ~24–48 hours
- **Best for:** Full-featured setup where budget allows

### Interakt
- **URL:** interakt.shop
- **Pricing:** US$15–50/month
- **Free trial:** Yes (14 days)
- **Australian support:** Limited (India-based, email/chat)
- **Strengths:**
  - Most affordable option
  - Simple interface, easy for non-technical owner
  - Quick template approval
  - Good for small businesses
  - Built-in CRM features
- **Weaknesses:**
  - Limited API for Phase 2 custom integration
  - Fewer analytics options
  - Smaller feature set for automation
- **Template approval:** ~12–24 hours
- **Best for:** Budget-conscious Phase 1, upgrade later if needed

### AiSensy
- **URL:** aisensy.com
- **Pricing:** US$25–75/month
- **Free trial:** Yes (14 days)
- **Australian support:** Limited (India-based)
- **Strengths:**
  - Good middle ground on features and price
  - Campaign scheduling built-in
  - WhatsApp chatbot builder
  - Drip campaign sequences
- **Weaknesses:**
  - Less established than WATI
  - API documentation less comprehensive
- **Template approval:** ~24 hours
- **Best for:** Balance of features and price

---

## Recommendation

**For Phase 1:** Start with **Interakt** — cheapest, fastest template approval, simplest for the owner to understand.

**For Phase 2+:** Evaluate migration to **WATI** when custom API integration becomes necessary. The cost difference (A$35/month vs A$80/month) matters less once the system is generating revenue.

**Migration path:** All platforms support CSV export of contacts and conversation history. Switching is a day's work, not a rebuild.

## Meta Conversation Pricing (Applies to All Platforms)

- **Marketing conversations:** ~A$0.07 per conversation (24-hour window)
- **Service conversations:** ~A$0.03 per conversation
- **Utility conversations:** ~A$0.01 per conversation
- **2,847 contacts × A$0.07** = ~A$200 per broadcast

This is on top of the platform subscription fee.
